# AGENTS.md

## What This Repo Is

The native SwiftUI iPhone app for RightTrain (UK rail departures, monitored
journeys, alerts and Live Activities). It was extracted from the
`paulbailey/infra` monorepo (`apps/clearsignal/ios`); history is preserved.

The backend is a separate **private** repository and the website is
`righttrain-web`. This app is a thin client over the backend's HTTP API
(`https://api.righttrain.app` in Release builds). The OpenAPI contract is owned
by the backend; the Swift models here are hand-written, so a backend API change
needs a matching change here.

## Layout

```
RightTrain/                       App target (SwiftUI)
RightTrainLiveActivityExtension/  Live Activity / widget extension
RightTrainTests/                  XCTest bundle
RightTrain.xcodeproj/             Xcode project (scheme: RightTrain)
scripts/                          TestFlight archive, screenshot capture, icon generator
design/                           App icon layers and the pinned UX board
docs/                             iOS brief, TestFlight readiness, screenshot capture
```

Minimum iOS is 26.0. Bundle identifier `com.righttrain.ios`.

## Build And Test

```bash
make build   # headless simulator build
make test    # XCTest on a simulator (override TEST_DESTINATION if needed)
```

iOS changes need an Xcode build or XCTest run; there is nothing to verify them
without one. Visual review screenshots (`make ios-screenshots-app`) are written
to `design/review-screenshots/`, which is git-ignored.

## Design Direction

- Standard iOS system colours (grouped backgrounds, label colours) with dark mode
  support; green is the accent. Native structure: inset-grouped List/Form, system
  Picker, visible navigation bars, toolbar menus; compact departure-board rows.
- Values a station departure board would show (clock times, countdowns,
  platform numbers) use the dot-matrix board face via `BoardFont`
  (`RightTrain/LiveActivity/BoardFont.swift`, font and OFL licence in
  `RightTrain/Fonts`). Prose, labels and controls stay in the system face, and
  nothing below subheadline size uses the board face.
- Do not reintroduce cream/editorial surfaces, tracked uppercase eyebrows,
  card-in-card chrome or light-only overrides.
- Liquid Glass only on floating/navigation controls (safe-area-bar primary
  actions, toolbar, banners, tab bar accessory). Content cards and list rows stay
  solid. `tabViewBottomAccessory(isEnabled:)` needs iOS 26.1, so it is gated with
  `#available`.

## Release Flow

TestFlight builds come from **Xcode Cloud**, whose workflows are configured in
App Store Connect, not in this repo. Two branches trigger them:

- `testflight-internal`: internal TestFlight group.
- `testflight`: external TestFlight group.

`make testflight-internal` / `make testflight` merge `main` into the branch and
push it. If a build fails on a missing SDK symbol, check the workflow's Xcode
version in App Store Connect. `scripts/archive-testflight.sh` is a local fallback
that archives and uploads from a Mac with the right signing account.

## Things To Know

- Debug builds default to a homelab hostname for the API
  (`RIGHTTRAIN_API_BASE_URL`); override it with a build setting or in the scheme to
  point at another backend.
- Never commit signing assets, provisioning profiles, API keys or `.p8` files.
  `RIGHTTRAIN_DEVELOPMENT_TEAM` and bundle identifiers are build settings.
- The web favicon set is generated by `scripts/generate-righttrain-icons.swift`
  and written to `../righttrain-web/public/icons` when that repo is checked out
  next to this one; otherwise only the app icon and design layers are written.
