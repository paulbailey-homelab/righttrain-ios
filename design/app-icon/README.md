# RightTrain app icon

Source layers for the Liquid Glass icon, generated by
`ios/RightTrain/scripts/generate-righttrain-icons.swift`. Re-run the script
after changing the geometry; it also regenerates the flat stand-in icon in
`AppIcon.appiconset` and the web icons in `frontend/public/icons`.

| File | Layer |
|---|---|
| `0-background.png` | Background (forest green gradient) |
| `1-tracks.svg` | The two diverging tracks |
| `2-route.svg` | The chosen route: dot, line and arrowhead |

Shapes are exported in white; colour and opacity are set per appearance in
Icon Composer.

## Assembling in Icon Composer

Open it from Xcode ▸ Open Developer Tool ▸ Icon Composer (needs macOS Tahoe
26.4 or later).

1. Drag in the three files in order, one group each.
2. Set the background fill to a linear gradient, top to bottom:

   | Appearance | Top | Bottom |
   |---|---|---|
   | Default | `#17704A` | `#0E4A30` |
   | Dark | `#10261C` | `#07140E` |
   | Mono | system default | system default |

3. Set layer colours:

   | Appearance | Tracks | Route |
   |---|---|---|
   | Default | white, 38% opacity | white |
   | Dark | `#4AC785`, 38% opacity | `#4AC785` |
   | Mono | 42% gray | white (the one prominent element) |

4. Glass: keep specular on the route group. If the thin tracks look pillowy,
   turn specular off for that group. Use neutral shadows.
5. Check the Default, Dark, Clear and Tinted previews and the small sizes,
   then export `RightTrain.icon`, add it to the RightTrain target and remove
   `AppIcon.appiconset`.
