Implementation rule

Every monitored surface gets a shared Pin header. The body can change by state, but the object identity stays stable.

Search PinRoute + time range + live recommendations. Primary action: pin a specific journey when the user commits.
Journey PinSpecific train or multi-leg route. Primary action: confirm boarding or recover when the user is not on the pinned journey.
Auto-pinSaved commute setting that creates a Pin around a schedule. It is not a third Pin type.
CopyUse Pin, Unpin, Replace current Pin, Pin search, Pin journey, Pinned now, and Not on this train/journey.
